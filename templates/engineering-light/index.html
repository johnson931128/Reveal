上電後，Master 先透過 Broadcast Command 對所有 Slave 執行共通操作，再利用 Auto Increment Addressing 依鏈路位置逐站存取 Slave。完成 Configured Station Address 配置後，Master 即可使用 Fixed Position Command，透過固定站址指定 Slave，再利用 ADO 存取該 Slave 的 ESC Register。

Auto Increment Command 用於依實體鏈路位置逐站存取 Slave。Master 可在 outgoing Datagram 中使用 0x0000、0xFFFF、0xFFFE 等 Auto Increment Address，分別表示 0、-1、-2，對應第 1、2、3 個拓樸位置。封包經過 Slave 時，Auto Increment Address 會依協定規則更新；Slave 在 Address 命中自身時執行該 Datagram 操作，因此 Analyzer 可以利用 outgoing ADP 重建 topology position。

Master 透過 ESC 的 EEPROM Interface Register 指定 SII Word Address、送出 EEPROM Read Command，再由 EEPROM Data Register 取得 SII 內容。ESC Register Address 與 SII EEPROM Word Address 屬於不同的 Address Space。

Master 先將欲讀取的 SII EEPROM Word Address 寫入 ESC EEPROM Address Register。此例指定 0x0008，對應 Vendor ID 的起始 Word Address。

Master 透過 EEPROM Control / Status Register 送出 Read Command。ESC 執行 EEPROM 存取期間會反映 Busy / Status，完成後資料可由 EEPROM Data Register 取得。

EEPROM Read 完成後，對應 SII Word 的資料出現在 ESC EEPROM Data Register。Master 可透過 APRD 讀取 ADO 0x0508，取得先前指定的 SII EEPROM 內容。

0x0502、0x0504、0x0508 位於 ESC Register Address Space，用來操作 EEPROM Interface；0x0008、0x000A 則位於 SII EEPROM Word Address Space，用來定位 EEPROM 內實際儲存的 Slave Information。兩者不可混為同一種 Address。

相同的 EEPROM Read 流程可以切換不同的 SII Word Address。例如以 0x0008 為起始位置讀取 Vendor ID，以 0x000A 為起始位置讀取 Product Code。
