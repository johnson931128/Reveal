上電後，Master 先以 Broadcast 對所有 slave 進行初始化與共通設定，再透過 Auto Increment / Configured Address 完成站點識別與位址建立。接著以 SDO Download 設定 PDO Mapping 與 SyncManager Assignment，再以 FPWR 寫入 SyncManager / FMMU 相關暫存器建立 process data path。當 slave 切換至 SAFEOP / OP 後，即以 LWR、LRD 或 LRW 進行週期性 process data 交換。

封包觀察

上電初期先會看到 Broadcast 對所有 slave 做全體初始化。接著 APWR 寫入 ADO 0x0010，建立 Configured Station Address；Analyzer 依 outgoing ADP 推得 topology position，將 station address 綁到該 slave。

讀取 slave identity 時，Master 先用 APWR 寫入 ADO 0x0502，並同時帶入 0x0504:0x0507 的 EEPROM Word Address，再用 APRD 讀取 ADO 0x0508。Analyzer 依先前指定的 EEPROM Word 判斷資料是 Vendor ID（0x0008）或 Product Code（0x000A）。

PDO Configuration

Address / ObjectConfigurationMeaning
0x1600 / 0x1A00PDO Mapping定義 PDO 內包含哪些 OD Index / SubIndex，以及每個 entry 的 bit length
0x1C12 / 0x1C13SM Assignment指定 RxPDO / TxPDO Mapping Object 所屬的 SyncManager

這一步不是立刻做 cyclic exchange，而是先決定哪些 object 會進 PDO，以及這些 PDO 由哪個 SyncManager 承接，讓後續 Process Data Path 可以建立。

這一步是把 PDO 組態結果落到實際傳輸路徑：SyncManager 決定 process RAM 的區段、長度與方向，FMMU 決定 logical address 對應到哪個 slave 的哪段 local memory。完成後，cyclic datagram 才知道資料路徑。

Cyclic Data

CommandData PathOperationTypical Use
LWRMaster → Slave Output Process Image寫入輸出資料常見於控制輸出更新
LRDSlave Input Process Image → Master讀回輸入資料常見於狀態 / 感測資料回讀
LRWRead + Write in one datagram同時讀寫雙向 cyclic exchange

「Master 寫入 Slave Output」是指主站把控制資料寫進 slave 的 output process image；「Master 讀取 Slave Input」是指主站從 slave 的 input process image 取回狀態 / 感測資料。slave 進入 SAFEOP / OP 後，才進入這種週期性 process data 交換。
